# Literary views inside each novel

16 October 2026. The geographic atlas is the default. The illustrated mode is called Vedute letterarie (Literary views, Vues littéraires, Vistas literarias) and is accessed only through the navigation inside a supported novel. There is no collection page, catalogue card or home link. The earlier imaginary.html collection has been removed.

The book navigation contains a current-mode label and one link to the other mode, preserving book, language and chapter/global hash. The internal mode=imaginary URL remains compatible with existing links; legacy illustrated.html opens the geographic novel by default.

The three novels retain independent geographic and illustration datasets. Imagery uses only image anchors, with no terrestrial coordinates or automatic geographic switching. Geography uses real places, documented models and regional diamonds. Introductions, source identities, quotations, narrative categories and layer numbering remain intact. Image exports cannot include geographic records. No database content or original text is changed.

Tests cover three books, four languages, source immutability, isolated points/exports, empty sections and the absence of collection pages or catalogue links. Publication uses the docs branch.
